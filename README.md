## 发布与维护

本仓库的 GitHub Pages 来源为 `master` 分支根目录。页面使用相对资源路径，可以直接运行于本仓库的项目子路径。

主站是主要维护版本。更新主站后，如需同步旧地址，将 `.gitignore`、`.nojekyll`、`index.html`、`styles.css`、`portfolio.css`、`app.js`、`resume.html` 和 `assets/favicon.svg` 同步到本仓库并提交。两个仓库之间当前没有自动同步工作流。

canonical、Open Graph 地址和复制链接按钮保留主站地址；独立域名也在主站仓库配置。
